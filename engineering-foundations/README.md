# Engineering Foundations
This directory documents my journey in understanding
the core concepts of software and data engineering.
## Purpose
The goal is to build strong engineering fundamentals
through conceptual understanding, practical application,
and real-world problem-solving.
This is not a collection of routine exercise solutions.
## Learning Areas
### Linux
- Filesystem and directory management
- Users, groups, and permissions
- Process management
- Shell commands and utilities
- Troubleshooting and practical scenarios
### Python
- Programming fundamentals
- Functions and error handling
- Data structures
- File handling
- Practical programming concepts
## Documentation Approach
For each concept, I aim to document:
1. What the concept means.
2. How and why it works.
3. Important edge cases and common mistakes.
4. Challenging real-world examples.
5. Key lessons learned.
